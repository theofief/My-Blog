# 🌐 Simple Post Viewer
Published version available [here](https://theofief.github.io/My-Blog/)

**Simple Post Viewer** is a lightweight, responsive web interface that fetches and displays posts from an external API with real-time search, dark mode toggle, and animated sidebar navigation ⚡

---

## ✨ Features

✅ Fetches and displays posts from an API  
✅ Live search with instant filtering  
✅ Dark mode with local storage support  
✅ Responsive sidebar navigation with animations  
✅ Clean and minimal UI  

---

## ⚙️ Requirements

- A modern web browser  
- Internet access (for API fetching)  
- Static server or local file opening support  

---

## 📁 File Structure
index.html
style.css
script.js

> No frameworks required — just pure HTML, CSS, and JS 💻
